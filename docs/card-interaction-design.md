# 一隅：卡牌沙盘正式交互方案

版本：0.9.0-trial.2 · 2026-10-27  
开发分支：`trial/card-prototype`  
状态：方案与可运行实现同步迭代，尚未合并主分支。

## 1. 设计目标

玩家通过摆放和改变一方天地，表达自己想要的环境、距离、边界和行动。界面应让玩家容易尝试、容易看见结果、容易反悔。保留已认可的底部扇形手牌与沙盘画面，以拖拽作为主要的卡牌操作。

核心循环：**拿起卡牌 → 拖向地图 → 看见预览 → 松手留下变化 → 观察或重新安排**。

卡牌承载可以理解的意图，系统补足光线组合、成组摆放和短桥拼接等操作细节。位置、朝向、物件之间的距离与组合继续由玩家决定。含义留给玩家自己解释；界面不生成心理评分或诊断结论。

## 2. 界面组成

- 沙盘为视觉主体，底部中心为手牌。天色、空间、旅程三个分类的位置保持稳定。
- 手牌平时收拢，鼠标进入后扇形展开；单卡悬停时上提、转正，露出卡名、插画、一句效果说明和作用范围。
- 同屏四张卡。低频的物件库、地形和路线细节按需打开。
- 撤销、重做、开始／暂停同行保持可找到，不放进卡组。
- 卡牌无数量消耗、冷却、费用、稀有度、牌序要求或限时选择。使用后仍留在手牌中。

## 3. 拖拽状态与行为

| 状态 | 界面反馈 | 场景是否改变 |
| --- | --- | --- |
| 收拢／展开 | 手牌围绕下方圆心展开；位置稳定 | 否 |
| 按下 | 保留卡牌位置，等待移动 | 否 |
| 拿起 | 移动超过 8 个屏幕像素后出现随指针移动的浮卡，原卡淡化 | 否 |
| 移至有效地图区域 | 地图边缘与浮卡显示可放下状态，出现“松手”提示及结果预览 | 否 |
| 移至无效位置 | 说明不满足的条件；浮卡提示换一处，不显示可放下状态 | 否 |
| 有效松手 | 卡牌施加变化，播放对应反馈；卡牌继续可用 | 是，一次完整历史记录 |
| 地图外松手／拖回手牌／Esc | 浮卡归还，预览撤回 | 否 |
| 指针取消／失去窗口焦点 | 结束拖拽，撤回预览与浮卡 | 否 |

拖拽期间捕获当前指针，屏蔽本次手势对地图摆放、平移及原有编辑事件的误触。小幅移动仍按点击处理。松手后抑制由同一次拖拽附带产生的点击事件，避免额外打开确认面板。

## 4. 两种作用范围

### 全局卡

白昼、黄昏、薄雾、细雨，以及两种行走节奏作用于整个场景或当前旅程。地图画布及其周围约 22 个屏幕像素为宽容投放区域；菜单、按钮和手牌等交互控件不接收投放。

天色卡进入投放区域后临时预览，离开即恢复已确认的环境。位置用于反馈动画的发起点，不决定天气只作用于某个局部。松手才保存变化。

光线和天气是两个独立通道：黄昏可以与雾或雨组合；白昼替换黄昏，细雨替换薄雾。效果标签可以移除对应通道。对已经生效的相同全局效果再次松手，不新增历史记录。

### 局部卡

空间卡和路线标记必须落在地图内的有效位置。拖动时，根据鼠标所在的格子或物件显示半透明结果、作用范围与简短提示。松手时重新验证，不使用过期的预览结果。

| 卡牌 | 有效对象／区域 | 结果与约束 |
| --- | --- | --- |
| 添一片树 | 陆地上的可用空格 | 在落点附近放置最多四棵树，跳过已有物件、路线标记与旅人位置 |
| 围一处 | 陆地 | 在落点附近放置小范围围栏；已有占用位置保留，预览明确显示实际段数，不保证必然形成闭合空间 |
| 留个入口 | 围栏或关闭的小门 | 将选定位置变成打开的小门，不移动其他物件 |
| 架一座桥 | 两岸之间的水面 | 查找横向或纵向可连接的两岸，选择较短跨度；两端需可通行，不越界或覆盖其他物件 |
| 经过这里 | 可通行陆地或桥 | 设置本段途经点，保留与起点、终点分开的规则 |
| 在此停留 | 可通行位置、长椅或角色 | 设置本段终点；角色与长椅沿用原有接近规则，不表示新增定时等待功能 |

卡牌提供快捷入口，自由移动、旋转、开关门等直接操作继续保留。无效落点不扣除任何资源，不形成失败结算。

## 5. 变化动效

动效需要说明“哪张卡造成了什么变化”，强度以不抢走玩家对场景的注意力为准。

| 操作 | 反馈 |
| --- | --- |
| 拿起卡牌 | 浮卡缩小、轻微倾斜，原卡淡化；随指针移动 |
| 黄昏／白昼 | 光线渐变，落点发出柔和扩散反馈 |
| 薄雾 | 雾层渐入，退出预览或取消时退回已确认天气 |
| 细雨 | 雨幕渐入，与现有天色组合 |
| 树木 | 成组树木从地面渐次长出，约 550 毫秒完成单株呈现 |
| 围栏 | 各段依次出现，轻微错开时间 |
| 小门 | 门扇约 700 毫秒展开，门柱保持稳定 |
| 木桥 | 桥段按空间顺序依次铺出 |
| 路线与节奏 | 落点扩散及简短状态反馈，标记或步调随之更新 |
| 取消 | 浮卡约 230 毫秒回到手牌；场景不保存临时效果 |

一组物件的错开时间有上限，避免长桥导致动画持续过久。动画期间拓扑与碰撞规则采用已经确认的最终结果；视觉渐入不形成额外操作步骤。撤销或载入场景时清除本次变化的残余动画。

遵循系统的减少动态效果偏好：保留状态、作用范围和文字反馈，关闭装饰扩散、粒子及物件生长动画，浮卡仍随操作位置移动。

## 6. 同行中的使用规则

- 天色与节奏变化不改变旅人的当前位置，不重新出发、不重开叙述。
- 开始预览空间或路线变化时暂停旅人，保证落点稳定。
- 取消空间或路线预览时，恢复预览前的行走位置和进度。
- 确认局部变化后保持暂停，便于观察；点击继续后按新布局寻路。
- 已经暂停的旅程不会因为取消预览而自动出发。
- 沿用原有撤销行为：撤销已确认的场景修改时旅人回到起点。

## 7. 点击、键盘与触屏

拖拽为主要路径；点击卡牌、选择位置并确认的路径继续完整可用。键盘可以通过常规焦点导航选择卡牌、确认或放回；Esc 取消当前预览或拖拽。局部落点目前仍通过鼠标或触屏选择，尚未实现全键盘布置。

鼠标、触屏使用同一套 Pointer Events 手势。卡牌区域阻止本次触摸手势触发页面滚动，地图原有双指缩放和平移保留。多指取消、失去指针捕获和窗口失焦都按取消处理。实际触屏手感仍需真机试玩验证。

## 8. 保存与版本

- 预览不写入场景、自动保存或撤销栈；有效松手才提交。
- 一张卡造成的一组变化是一条历史记录，整步撤销、重做。
- 环境与节奏保存在场景状态内，随存档和历史恢复。
- 延续前一轮卡牌试用版的存档槽；与基础沙盘的存档分开。
- 保留原初版 HTML 作形式对照。本轮独立导出拖拽方案版，不覆盖原文件。
- 代码、方案、测试在 `trial/card-prototype` 分支管理，主分支暂不合并。

## 9. 本轮验收与范围

已具备：12 张卡、扇形手牌、拖动预览、松手施加、无效归还、点击替代路径、效果组合、成组撤销与保存，以及变化动效。

自动检查覆盖：轻微移动与拖拽阈值、有效投放、地图外取消、指针取消、全局重复操作、空间预览恢复原行走位置、天气不重启同行、成组撤销和动画过期。原有寻路、标记、地形和叙述回归检查保留。

浏览器已实测：黄昏卡拖入生效、薄雾卡在地图外松手取消、树木卡投放与整组撤销。桌面鼠标为本轮主要体验设备。

本轮保留的边界：天气仅有视觉效果；围栏范围固定；桥采用横／纵两岸规则；路线仍有一个必经点；图片导出暂不包含天气遮罩。声音、更自由的围合形状与角色同行关系作为后续独立迭代项。

后续试玩优先观察：玩家能否发现拖拽、能否理解全局和局部的区别、是否清楚何时真正生效、无效落点能否自行调整，以及卡牌选项是否限制了原本想表达的安排。
