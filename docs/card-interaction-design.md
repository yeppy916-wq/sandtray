# 一隅：卡牌沙盘正式交互方案

版本：0.10.0-trial.1 · 2026-10-27
开发分支：`trial/card-prototype`
最终交互方向：自由摆放资产，拖拽卡牌改变环境、相处与旅程。

## 1. 已确定的设计原则

沙盘用于表达玩家想要的环境、距离、边界和行动。保留已经认可的底部扇形手牌，以及“拿起 → 拖向地图 → 预览 → 松手留下变化”的连续手势。

本轮增加可表达的安排与组合，操作步骤保持稳定。资产创建、地形绘制、房屋与装饰摆放、围栏和桥的建造仍由物件库直接操作，不进入卡牌。简单开关门仍直接点击。

卡牌可重复使用，不加入费用、冷却、稀有度、限时选择、胜负评分或强制随机抽取。作品的含义由玩家决定，不从卡牌选择自动生成心理判断。

## 2. 二十张表达卡

### 天色：8 张

| 卡牌 | 作用 | 组合通道 |
| --- | --- | --- |
| 晨光 | 较明亮、温暖的清晨光线 | 光线 |
| 黄昏 | 柔和暮色 | 光线 |
| 月夜 | 保留场景可读性的夜色和星点 | 光线 |
| 薄雾 | 让景物隐入雾层 | 天气 |
| 细雨 | 渐入的雨幕 | 天气 |
| 飘雪 | 缓慢落下的雪花 | 天气 |
| 微风 | 风带过少量叶片 | 风 |
| 秋色 | 暖色的风景基调 | 色彩 |

光线、天气、风、色彩四个通道可以独立组合。例如“月夜＋飘雪＋微风＋秋色”会同时保留四种效果。同一通道的新卡替换旧效果，不持续叠加深色滤镜。

恢复白昼、无天气、无风或原色，都通过已生效标签的 × 完成，不再占用“恢复”卡。卡面上的小圆点表示这张全局卡已经生效。

### 相处：6 张

| 卡牌 | 作用对象 | 结果 |
| --- | --- | --- |
| 靠近一点 | 一个已有动物或人物 | 向旅人走近，单次最多移动两格 |
| 留点距离 | 一个已有动物或人物 | 与旅人拉开距离，单次最多移动两格 |
| 聚在一起 | 选中的已有角色及附近角色 | 以选中者为中心，最多让四个附近角色走近 |
| 各留一隅 | 一组已有角色 | 最多四个角色向群组外散开 |
| 安静相处 | 当前同行方式 | 沿途不主动展开叙述或对话，仍可手动聊聊 |
| 相遇聊聊 | 当前同行方式 | 遇见角色时停下来，展开可回应或跳过的片段 |

位置卡只移动已有角色，角色数量不变。候选移动通过空地搜索产生，不穿过水、围栏或其他障碍，不覆盖资产，不占用起点、途经点或旅人所在位置。分组移动依次预留位置，避免多个角色落在同一格。

选取角色时优先检查角色自身的可点击区域，减少前景树木挡住角色落点的情况。预览用半透明身影和方向箭头表示“从哪里走到哪里”。作为终点的角色移动时，终点随它一起移动。

若附近没有其他角色，聚散卡提示先用物件库安排角色，不自动生成角色。若没有有效空位，保持原状并说明原因。

默认同行方式为轻声描述风景。点击同行方式标签的 ×，即恢复这一默认状态，不设置“恢复轻声”卡。

### 旅程：6 张

| 卡牌 | 作用 |
| --- | --- |
| 慢慢走 | 较慢步调 |
| 轻快些 | 较快步调 |
| 从这里出发 | 设置起点 |
| 经过这里 | 设置一个必经点 |
| 在此停留 | 设置本段终点，可选空地、长椅或已有角色 |
| 换个方向 | 交换出发与到达方向，保留必经点 |

“换个方向”投向地图区域即可预览整段路线变化。如果原终点是角色或长椅，使用它附近可通行的位置出发；无法找到可出发位置时不修改路线。

平常步调通过移除节奏标签恢复，不再单列“照常走”。“在此停留”表示本段终点，不表示新增计时等待机制。

## 3. 卡组浏览与界面精简

三个分类显示各自数量：天色 8、相处 6、旅程 6。每次最多展开四张；箭头切换同一分类的另一组，末组只有两张时居中显示。每个分类记住本次打开页面内的浏览位置。

手牌保持底部中心扇形结构，悬停抬升、点击固定展开、拖动浮卡与无效归还继续保留。分类与翻组按钮位于独立前景层，避免被折叠卡片遮住。窄屏将分类和翻组分为两行，缩小卡片扇面跨度。

移除或合并的重复入口：

- 添树、围栏、入口、架桥不再是卡牌；对应资产与编辑能力继续存在于物件库和地图直接操作中。
- 白昼、平常步调等恢复动作合并到生效标签。
- 同行节奏设置合并到相处卡，开始旅程不再重复弹出节奏问答。
- 起点、必经点、终点通过旅程卡安排，常驻路线详情面板隐藏。
- “查看路线”只切换路线显示，网格与镜头仍在视角菜单中。
- “旅人回到起点”收进沙盘选项，保留重新观察同一段旅程的能力。
- 移除版本试验文字和重复的操作提示，缩短地图标题与空白叙述提示。

物件库不删减原有资产，仍支持放置、移动、旋转和移除。卡牌不会阻止玩家继续手工安排。

## 4. 拖拽与生效规则

| 状态 | 反馈 | 是否修改场景 |
| --- | --- | --- |
| 收拢／展开 | 稳定的扇形手牌 | 否 |
| 移动超过 8 个屏幕像素 | 浮卡跟随指针，原卡淡化 | 否 |
| 全局卡移到地图及其附近 | 环境临时预览、边缘提示 | 否 |
| 角色或路线卡移到有效对象 | 身影、箭头或标记预览 | 否 |
| 有效松手 | 施加变化，记录一次历史 | 是 |
| 无效位置松手／地图外松手／Esc | 归还卡牌，撤回预览 | 否 |
| 指针取消／窗口失焦 | 结束手势，恢复预览前状态 | 否 |

地图附近约 22 个屏幕像素作为全局卡的宽容投放区域；菜单、按钮和手牌不接收投放。局部卡必须落到有效角色或地图格子，松手时再次验证结果。

浮卡偏置显示，尽量让开角色与落点；靠近窗口边缘时换到指针另一侧。点击卡牌、选择位置并确认的替代路径继续保留。键盘可以选择、确认或取消；局部落点仍需鼠标或触屏。

## 5. 动效与同行

环境采用柔和过渡、落点扩散和少量粒子；风与雪使用独立层，秋色和光线通过可组合的基调呈现。角色从原位置滑向新位置，群组移动略微错开时间，不播放资产生成动画。路线更新显示对应标记。

环境与同行方式的改变不重启旅人。角色位置和路线预览会暂时暂停旅人；取消恢复预览前的精确位置与行走进度，确认后保持暂停，便于观察再继续。原先已经暂停的旅程不会自动出发。

一次群组修改是一条完整历史记录。撤销、重做或载入场景时清除残余动效。沿用原有撤销行为：撤销已确认的场景修改时旅人回到起点。

遵循减少动态效果偏好，保留作用范围、状态与文字反馈，关闭装饰粒子和角色移动动画。天气目前仅提供视觉效果；实际触屏手感仍需真机验证。

## 6. 保存与版本

预览、翻组和切换分类不写入场景或撤销栈。只有正式生效才保存。独立环境通道、步调和叙述方式都属于场景状态，随历史与存档恢复。

继续使用卡牌试用版的独立存档槽，可读取前一轮卡牌沙盘。保留旧版 HTML，新增“表达扩展版”作为本轮入口。源代码、正式方案与测试继续在 `trial/card-prototype` 管理，主分支不自动合并。

## 7. 验证范围

自动检查包括：20 张卡的唯一性与分类数量、建造卡退出卡组、四张一组的翻组、环境通道独立性、默认状态恢复、已有角色数量守恒、群组移动撤销、障碍限制、角色终点跟随、起点修改、路线反转、拖拽取消、同行进度恢复和存档迁移。原有资产摆放、地形、寻路与叙述回归检查继续保留。

浏览器检查覆盖窄屏分类与翻组、相处卡实际投放、环境组合，以及精简后的主要入口。后续试玩继续关注卡名是否易懂、是否能发现另一组卡、聚散结果是否符合预期，以及可选表达是否仍然受到卡组限制。
