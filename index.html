这个世界的规则

空白沙盘是一片大海；选择陆地材质后拖动绘出岛屿，也可重涂已有陆地。水域工具或橡皮可把陆地还原为海。三个路线点需分别设置，途经点必须经过；水、树、石头、围栏会挡路；门打开后可通过；桥只沿木板方向通行。把终点设在长椅上，旅人会走到椅旁，再坐下。没有路线时留在原地，浅绿色显示当前可达区域。

给空间一个小小的变化

沙盘的基底是大海。“空白沙盘”会清空为海面，先选择草地、沙地、泥土或石地，按住拖动创建陆地；在现有陆地上涂绘仅更换材质，保留物件。再设置三个路线点。当前示例只提供一个途经点，自适应数量仍为后续设计，详见左侧说明。

默认使用正面视角，仅提供“正面 / 左前 / 右前”三个稳定观察角度。点击对应按钮切换；Home 恢复正面远景，[ / ] 在三个角度间切换。外形为不规则基底，实际编辑区域仍有限；勾选“显示网格”可查看可编辑范围。远景查看完整岛屿，近景观察旅人和物件。滚轮围绕指针缩放；右键拖动平移；空地也可拖动；触屏使用双指。点击“归位”恢复完整视野，“跟随旅人”让镜头随角色移动。

本版新增“同行者”：使用环境、动物、人物三个分类摆置场景，点击“开始同行”。靠近动物和人物时，会触发预写片段与三个回应选项。可以跳过回应，或留一句话后继续。选择“轻声描述”只显示沿途字幕；“安静同行”不自动弹出文字；“此刻聊聊”可主动停下来。

动物和人物可作为终点，旅人会走到角色旁边。自动相遇有三个行走格的间隔，每次旅程最多六次，避免文字过密。故事只依据实际放置的物件触发，不会自动分析物件的心理含义。所有片段使用本地规则与预写对话，不接入 AI。

  1. 使用“查看 / 移动”，点击示例庭院左边带“门”标记的物件，将门打开。
  2. 点击“开始同行”。旅人会跨过桥、穿过门，在长椅上停留。
  3. 点击“回到起点”，关门、移走一段桥，或重新安排物件，再试一次。
  4. 选择“设置起点 / 途经点 / 终点”，点击沙盘，三个点需分开放置。途经点放在可通行的陆地或桥上；旅人先经过它，再走向终点。终点可以是空地、长椅，也可以是动物或人物；遇见角色时会停在其旁边。
  5. 选择物件后点击放置；陆地、水域、围栏、橡皮支持按住拖动连续操作。查看模式下可拖动物件。

试走时先暂停再编辑。暂停会让旅人停到最近的格子中心；继续时按新布局重新计算路线。撤销和重做会让旅人回到起点。

桥只能放在水上。横向桥只能左右通行，纵向桥只能上下通行；宽河需要连续铺设多段桥。选中桥后按 R 旋转，也可以切换放置工具的方向。
