# Sandtray · 一隅

一个以空间摆置与行走反馈为核心的浏览器沙盘游戏原型。玩家创建陆地、选择材质并摆放物件，再安排“起点 → 途经点 → 终点”，观察旅人如何穿过自己构建的空间。

当前版本为 **0.7**：保留原版不规则基底、山体、岸线、植被、河道与默认物件布局，在其上增加一个可设置的途经点。游戏使用 Canvas 绘制 2.5D 场景，运行时不依赖服务器、外部图片或网络请求。

## 直接运行

下载仓库后，用现代浏览器打开根目录的 [index.html](index.html)，即可离线游玩，无需安装依赖或启动服务。示例中庭院的小门默认关闭：先使用“查看 / 移动”点击小门打开，再预览路线或开始同行。

## 主要功能

- **三点路线**：分别设置或拖动起点、一个途经点和终点；旅人必须先经过途经点，再抵达终点。
- **分段寻路**：门、围栏、树木、石头与桥的方向影响通行；任一段不可达会提示。终点可设在空地、长椅、动物或人物处。
- **暂停编辑与续走**：暂停后调整场景，继续时从旅人当前位置重新寻路；已到达的途经点不会被重复要求经过。
- **海面与陆地编辑**：空白沙盘从海面开始，可绘出陆地，并选择草地、沙地、泥土、石地。重涂已有陆地保留物件，橡皮优先移除物件，再将空陆地还原为海。
- **场景观察**：正面、左前、右前三个固定观察角度，以及缩放、平移和跟随旅人。
- **同行叙事**：可摆置动物与人物，通过本地规则触发预写片段与回应；支持安静同行、轻声描述和相遇时停留。
- **本地记录**：场景自动保存在当前浏览器；支持撤销、重做、画面导出和沿途记录导出。沿途记录仅保留在本次页面会话内，刷新前需自行导出。

## 途经点数量自适应：后续设计

当前示例固定 **一个**途经点，尚未实现自动增减。后续可先按可编辑沙盘面积划分规模，建议小型 1 个、中型 2–3 个、大型 4–6 个，再结合玩家创建的陆地面积、连通性和可通行路径长度调整建议。

沙盘扩缩后只更新建议数量，保留玩家已设置的点，由玩家决定增减与顺序；镜头缩放不改变数量。上述区间是待体验验证的设计建议。

## 开发与验证

构建需要 Python 3.10 或更新版本；测试需要 Node.js 20 或更新版本。Python 构建脚本只使用标准库，Node 依赖仅用于开发阶段的 Canvas 渲染测试。

```sh
# 从源码重新生成唯一的可运行入口
python prototype/build.py

# 安装锁定的开发依赖并执行测试
npm ci
npm test
```

测试覆盖脚本语法、门与桥的通行规则、必须经过途经点的绕行、不可达路段、旧存档迁移、标记拖动、暂停续走、陆地材质编辑、撤销重做，以及同行叙事的暂停和恢复。测试生成的图片位于 `.artifacts/`，不提交到仓库。

当前地图已在导入前与原版在三个观察角度进行像素对照，隐藏新增途经标记后画面一致。构建仅重新组装已有源码，不会重新设计地图。

## 项目结构

```text
index.html                   当前可离线运行的完整版本
prototype/
  base-template.html         构建所需的基础页面与游戏逻辑模板
  build.py                   组合模板、渲染器、样式和功能层
  renderer-v2.js             场景渲染、镜头与指针交互
  art-softcel.js             连续地表、海岸及缓存精灵绘制
  route_feature.py           三点路线与陆地编辑功能组装
  route-style.css            路线与材质工具样式
  story_feature.py           同行叙事功能组装
  narrative.js               事件触发、对话、节奏与沿途记录
  narrative-sprites.js       动物与人物精灵
  story-data.json            预写故事片段
  *style*.css                界面与叙事样式
tests/
  check-core.cjs             无界面核心规则检查
  render-scene.cjs           渲染与交互回归检查
```

修改故事 JSON 后，需要重新构建，变更才会嵌入 `index.html`。

## 数据与仓库边界

游戏没有账号、后端、AI 接口、分析上报或运行时网络依赖。场景存档位于浏览器本地，沿途文字由玩家主动导出。

仓库仅包含当前游戏、必要源码、测试和开发说明。依赖目录、缓存、环境变量文件、凭据文件、编辑器配置、生成图片、历史压缩包、备份和本地工作目录通过 `.gitignore` 排除。提交使用明确文件清单，避免把整个本地工作目录加入版本控制。

本项目用于沙盘启发的游戏交互探索，叙事含义由玩家决定，不作心理诊断或治疗效果声明。
